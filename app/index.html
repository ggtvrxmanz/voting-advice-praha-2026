    Jak se počítá skóre

    Server vybere započitatelné pasáže (1) a spočítá jejich skóre (2). Prohlížeč z nich určí skóre strany pro každé tvrzení (3) a celkové pořadí (4).

    (1) Kp(q)= {i∈Rp(q): reli=1, quote_oki=1, ci≥τ}
    (2) si=ci·sti, ci∈{0,25;0,5;0,75;1}, sti∈{−1;−0,5;0;0,5;1}
    (3) Sp(q)= { si*,i*=arg maxi∈Kp(q)|si| pokudKp(q)≠∅ 0 jinak (bez postoje)
    (4) Scorep= 1|𝒬| ∑q∈𝒬 Sp(q), Coveragep= |{q:Sp(q)≠0}|
    q, 𝒬
    jedno vaše tvrzení; všechna vaše tvrzení (|𝒬| = jejich počet, 1 až 5)
    Rp(q)
    pasáže programu strany p nalezené k tvrzení q (5 nejpodobnějších podle embeddingu)
    reli, quote_oki
    model uznal pasáž za relevantní; citace je doslovně obsažena v pasáži
    ci, τ
    jistota modelu u pasáže; nejmenší jistota, která se ještě započítá (zvolená týmem na vývojových datech)
    sti, si
    postoj pasáže (−1 odmítá … +1 podporuje); skóre pasáže = jistota × postoj
    Kp(q)
    započtené pasáže strany p k tvrzení q; ostatní se počítají jako „bez postoje“
    Sp(q)
    skóre strany u tvrzení: nejsilnější započtená pasáž (největší |si|)
    Scorep
    číslo v celkovém pořadí: průměr přes všechna vaše tvrzení
    Coveragep
    „Doloženo u … tvrzení“: počet tvrzení, kde má strana nenulové skóre
    Pro vývojáře: jak připojit vlastní pipeline

    Stránka při načtení zavolá GET {API_BASE}/api/health. Když odpoví, pošle tvrzení na POST {API_BASE}/api/analyze. Když server neodpoví, běží v ukázkovém režimu se simulovanými výsledky.

    POST /api/analyze
{ "claims": ["Praha by měla postavit více obecních bytů", "…"] }

→ 200
{ "queries": [
    { "claim": "Praha by měla postavit více obecních bytů",
      "results": [
        { "party": "Strana X", "quote": "Postavíme 6 000 obecních bytů…",
          "page": 9, "score": 0.38, "confidence": 0.75, "url": "https://…/program.pdf" }
      ] }
  ] }

→ 4xx/5xx   { "error": "Text chyby pro uživatele" }

    score je číslo od −1 (program tvrzení odporuje) přes 0 (nevyjadřuje se) po +1 (podporuje). confidence je nepovinné (1 / 0,75 / 0,5 / 0,25): jak si je model u pasáže jistý. score už jistotu obsahuje (score = jistota × postoj), stránka ji jen zobrazuje. url je nepovinné. Celkové pořadí se počítá v prohlížeči. Pro každou stranu a tvrzení se vezme pasáž s nejsilnějším skóre (největší absolutní hodnota), strana bez pasáže dostane 0 a výsledkem je průměr přes tvrzení. Pokud server vrátí vlastní pole ranking, použije se místo toho.
